Command-line access

    

      For curl and scripts run by a human. The device authorization grant
      (RFC 8628) is the only standard grant that gives a CLI a brokered identity —
      you approve it here, in a browser, and the terminal receives the token.
    

    
# once, to register this machine — prints a code to approve in a browser
oidc-gen meteogate --flow=device --manual \
  --iss=__ISSUER__ --client-id=federation-cli \
  --scope='openid profile email offline_access'

# thereafter
curl --oauth2-bearer "$(oidc-token meteogate)" \
  'https://__DATA_HOST__/api/birds?q=finch&limit=3'

What this page is actually doing

The URL bar cannot carry an Authorization header, so every request on this page — including each illustration — is made with fetch() and the header attached in JavaScript. Images arrive as bytes and are turned into blob URLs, because <img src> would send no credential at all. That constraint is the whole reason a data service needs either a web client like this one or a gateway session.

The gateway also offers a third way in: sign in at the gateway itself and get a session cookie, after which pasting a URL into the address bar simply works.
